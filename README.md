 # Automotive Engine Fault Detection Using FFT and Spectral Analysis of Acoustic Signals     


## 📌 Project Overview
A MATLAB-based Digital Signal Processing (DSP) project that analyzes engine sound recordings to identify acoustic differences between normal and potentially faulty engine conditions using FFT, spectral analysis, and acoustic feature extraction.

## ✨ Key Features
- **Time-Domain Analysis:** Visualizes engine sound signals.
- **FFT Analysis:** Identifies dominant frequency components.
- **Acoustic Feature Extraction:** Calculates RMS amplitude, spectral centroid, and spectral energy.
- **Harmonic Analysis:** Examines harmonic content and harmonic-to-nonharmonic energy ratio.
- **Engine Order Analysis:** Analyzes frequency components relative to engine RPM.
- **Acoustic Level Analysis:** Compares relative sound levels in dBFS.
- **Background Noise Estimation:** Estimates the spectral noise floor.
- **Anomaly Detection:** Identifies unusual spectral peaks using threshold-based analysis.
- **Crest Factor Analysis:** Examines impulsive characteristics of engine sounds.
- **Feature Comparison:** Compares normal and test engine recordings.

## 🛠️ Technologies Used
- MATLAB
- Digital Signal Processing (DSP)
- Fast Fourier Transform (FFT)
- Spectral Analysis
